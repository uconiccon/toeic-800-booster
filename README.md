# 🚀 TOEIC 650 → 800 Booster (90-Day Challenge)

> A lightweight, scientifically grounded study support dashboard built to elevate your TOEIC score from 650 to 800+ in 90 days (270 study hours). Inspired by the coaching principles of PROGRIT and Second Language Acquisition (SLA) theory.

---

## 📌 Overview

Crossing the threshold from **TOEIC 650 to 800** requires more than just passive practice—it demands **high-density deliberate training** and systematic habituation. 

At 650, test-takers typically hit two major cognitive bottlenecks:
1. **Listening:** Working memory is overwhelmed by *sound perception* (missing linked sounds, reductions), leaving little cognitive capacity for *comprehension*.
2. **Reading:** Sub-vocalization and regression (reading backward) limit reading speed to ~110–120 WPM, causing test-takers to run out of time in Part 7.

This standalone application provides the exact daily framework, timers, and metrics needed to automatize sound perception via shadowing and push reading speeds past **150 WPM**.

---

## ✨ Key Features

- **📊 Daily Habit & Task Tracker:**  
  Curated 3-hour/day training syllabus (Vocabulary speed-drills, Part 5 speed attack, Part 3/4 intensive shadowing, and Part 7 slash reading).
- **⏱️ 3-Step Shadowing Timer:**  
  Dedicated timer segmented for the SLA-backed 3-phase flow: *Oral Reading → Overlapping → Pure Shadowing*.
- **⚡ WPM (Words Per Minute) Speedometer:**  
  Instant reading speed calculator with real-time diagnostic feedback tailored for TOEIC Part 7 passage lengths.
- **📈 90-Day KPI Dashboard:**  
  Tracks cumulative study hours toward the 270-hour milestone with automated day-by-day progression.
- **💾 Local Persistence:**  
  All progress and logs are stored locally via `localStorage`—no servers, sign-ups, or database configuration required.
- **📱 Fully Responsive & Zero Dependencies:**  
  Single-file HTML with Tailwind CSS (CDN). Works smoothly on desktop and mobile browsers.
